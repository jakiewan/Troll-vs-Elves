# Troll vs. Elves · 雪林防线

原创雪林场景的单机网页塔防游戏，参考经典“精灵建家、巨魔攻墙”的玩法。玩家操控一名精灵，在固定基座发展经济、封锁窄口、修墙与升级防御塔，抵御逐渐强化的巨魔。

## 本地启动

在项目根目录运行：

```bash
python3 -m http.server 8765 --directory game --bind 127.0.0.1
```

打开 **http://127.0.0.1:8765/**。游戏为静态网页，不需要安装 npm 依赖。

## 当前玩法

- 标准局：30 金、0 木开局，巨魔在 30 秒后入场，每 90 秒强化，回店补给并换装后继续进攻。
- 精灵阵亡即失败，巨魔阵亡即胜利；另有免费建造与升级的练习场。
- 唯一窄口只能建一堵主墙；墙有实体阻挡，精灵近身持续修墙免费。
- 房屋与金矿产金；精灵直接建矿，远古之树通过连续升级提高产木。
- 防御塔逐阶升级，支持攻击、治疗、真视附塔及冰霜、毒伤等效果；只有一个可用升级时，点击一次就开始升级。
- 技能包含闪烁、缠绕、护盾、沉默和侦察守卫；支持 1、2、4、8、16、32 倍速。

## 操作

点地图移动，拖动平移，滚轮缩放；建筑只能放在固定基座。选中建筑后使用底部命令。电脑快捷键：

| 按键 | 操作 |
| --- | --- |
| 1 / 2 / 3 / 4 | 建房 / 建墙 / 建塔 / 建远古之树 |
| U / R / S | 升级 / 修墙 / 停止 |
| Q / E / Z / W | 闪烁 / 缠绕 / 护盾 / 沉默 |
| B / F1 / 空格 | 建筑目录 / 选择精灵 / 定位精灵 |

手机请横屏游玩。

## 验证与项目结构

```bash
node game/test.mjs
```

测试覆盖墙体碰撞、施工与修理、经济与升级、技能装备、胜负结算，并使用标准资源运行完整单机战局。

- `game/game.mjs`：界面、输入、绘制与动作效果。
- `game/simulation.mjs`：寻路、施工、经济、战斗与技能规则。
- `game/classic-data.mjs`：经典玩法的数值参考数据。
- `game/assets/`：本地场景、建筑、角色动作与图标。

更多细节见 [游戏说明](game/README.md) 和 [原创素材说明](game/ART_NOTES.md)。仓库不包含 Warcraft III 原地图、MPQ、研究提取文件或原游戏美术素材。
