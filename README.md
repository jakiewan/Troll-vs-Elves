# Troll vs. Elves · 雪林防线

一款正在开发的单机网页塔防游戏，参考 Warcraft III RPG 地图 **Troll vs. Elves v4.7 B5.5** 的建家、防守与经济成长机制，使用原创雪林场景和角色素材。

玩家操控一名精灵：先建房产金，在唯一窄口筑墙，再用防御塔、免费修墙和主动技能抵御巨魔。巨魔会攻墙赚钱、定期强化，并返回商店补给和换装。

**当前版本：单精灵、单巨魔、固定建筑基座。刷新页面或点击重置会清空本局，尚未实现存档和多人联机。**

仓库：[jakiewan/Troll-vs-Elves](https://github.com/jakiewan/Troll-vs-Elves)

## 1. 下载并启动

需要 **Python 3** 和现代浏览器。游戏使用 HTML、CSS、JavaScript 与 Canvas，启动时不需要安装 npm 依赖、数据库或后端服务。Node.js 仅用于运行模拟测试。

```bash
git clone https://github.com/jakiewan/Troll-vs-Elves.git
cd Troll-vs-Elves
python3 -m http.server 8765 --directory game --bind 127.0.0.1
```

浏览器打开：**http://127.0.0.1:8765/**

终端服务运行期间可以游玩，按 `Ctrl+C` 停止服务。请通过 HTTP 地址打开游戏；直接双击 `game/index.html` 可能导致 JavaScript 模块加载失败。

如果 8765 端口已被占用，把命令中的端口改成 8766，再访问 `http://127.0.0.1:8766/`。

### 手机通过局域网试玩

电脑与手机连接同一 Wi-Fi，在项目根目录运行：

```bash
python3 -m http.server 8765 --directory game --bind 0.0.0.0
```

查看电脑的局域网 IP，在手机浏览器访问 `http://电脑的局域网IP:8765/`。例如电脑 IP 为 `192.168.1.20`，手机访问 `http://192.168.1.20:8765/`。手机请横屏；访问失败时检查 Wi-Fi、电脑防火墙与服务是否仍在运行。

## 2. 开局模式与胜负

| 模式 | 起始资源 | 巨魔行为 | 用途 |
| --- | --- | --- | --- |
| 标准局 | 30 金、0 木 | 自动入场、强化、回店补给再攻 | 完整单机对局 |
| 练习场 | 5,000 金、200 木 | 点击“巨魔攻墙”手动开始 | 熟悉建筑、塔型和技能 |

练习场建造、建筑升级和附塔免费，免科技前置；交易、修理工雇佣和巨魔商店购买仍使用各自资源。练习场仍需等待施工和升级完成。

标准局的时间按游戏内时钟计算：

- `00:30`：巨魔隐身入场，可用侦察守卫揭示。
- `02:00`：第一次强化；之后每 90 秒强化生命、攻击和护甲。
- 巨魔进攻一段时间后会回店补给、购买装备，再沿入口进攻。
- 玩家精灵死亡：巨魔获胜。巨魔死亡：精灵获胜。

右上角可查看巨魔当前攻击、护甲、生命与资源；选中巨魔可查看回复和攻速加成。

## 3. 第一次怎么玩

1. 推荐先进入练习场熟悉操作，再尝试标准局。
2. 按 `1` 或点击“建小屋”，再点小屋基座。免费的帐篷建成后产生 **1 金/秒**。
3. 按 `2`，点击金色窄口基座建主墙。初始墙消耗 **4 金**，封住巨魔进入营地的路线。
4. 按 `3`，在墙后塔基座建基础塔，消耗 **16 金**。
5. 选中主墙，按 `R` 持续免费修理。精灵必须走到墙边；移动或停止命令会中断修理。
6. 随着金币积累，升级墙、房屋和塔；通过建筑目录建大厅，解锁后续科技和资源交易。
7. 建远古之树并升级产木，积累木材后建金矿、发展高阶墙塔。配合护盾、缠绕和侦察守卫守住入口。

施工命令可以排队。精灵会依次走近并建造；危急时选墙按 `R`，修墙会优先执行并取消施工队列。未完成建筑可以选中后继续施工。

## 4. 建筑与经济

### 固定位置与升级

每个营地最多 **1 堵主墙、3 座防御塔**，其他建筑类型各有一个固定基座。墙有实体碰撞；被击毁后，巨魔可以通过窄口追击精灵。

建造需要精灵到场；升级由建筑自行完成，耗时 **2.5 游戏秒**。升级期间墙继续阻挡、已建成经济建筑继续生产。

点击升级按钮时，系统会检查科技前置和资源：只有一个可用升级或附塔时直接开始；有多个可用选项时打开选择面板；资源或科技不足时需要先补齐条件。

### 金币怎么增加

**每秒金币收入 = 已建成房屋的收入 + 已建成金矿的收入。** 建筑处于施工状态时不产资源。经济面板会显示收入组成。

房屋有 10 档，收入从 1 金/秒提升到 512 金/秒，升级消耗金币、木材，并要求相应墙体或科技。

金矿由精灵直接建造，当前版本无需采金者或金矿建造者。建矿和升级矿主要消耗木材：

| 金矿阶段 | 建造或从上一阶升级的木材费用 | 建成后金币/秒 |
| --- | ---: | ---: |
| 史前金矿 | 32 | 1 |
| 旧金矿 | 256 | 8 |
| 金矿 | 1,024 | 32 |
| 超级金矿 | 4,096 | 256 |
| 超能金矿 | 16,384 | 1,024 |
| 巨型金矿 | 65,536 | 2,048 |
| 终极金矿 | 262,144 | 8,192 |
| 欧米伽金矿 | 999,999 | 98,304 |

升级替换原矿等级，表中的收入是当前矿的总收入，各级收入不叠加。

### 木材怎么增加

当前版本只保留 **一个可升级的采木建筑**：远古之树建成后自动产木，之后沿同一条链升级为伐木场。没有采木者招募列表，也没有采木人口上限。

| 采木建筑阶段 | 建造或从上一阶升级的金币费用 | 当前建筑木材/秒 |
| --- | ---: | ---: |
| 远古之树 | 256 | 0.333 |
| 基础伐木场 | 512 | 0.458 |
| 简易伐木场 | 1,024 | 0.583 |
| 专业伐木场 | 2,048 | 0.833 |
| 复合伐木场 | 4,096 | 2.333 |
| 秘银伐木场 | 20,480 | 12.333 |
| 离子伐木场 | 81,920 | 36.333 |
| 超声伐木场 | 262,144 | 216.333 |
| 终极伐木场 | 999,999 | 2,592.333 |

标准局建远古之树需要大厅。产量表保留三位小数，实际计算使用完整精度；每行表示该等级的总产量。

木材用于金矿、高阶墙塔、实验室与部分附塔等升级。大厅建成后可以交易金木，连续买入会涨价，连续卖出会降价；批量交易按逐笔变价计算。

### 修理与辅助单位

精灵近身持续修墙 **不消耗金币或木材**；墙升级需要支付资源。修满后保留修理指令，等待下一次受击。

工人行会可以雇佣修理工，自动到墙后辅助修理，最多 12 名。修理工负责修墙，不生产金币或木材。

## 5. 防御塔、技能与商店

主塔有 13 档，按相邻等级升级。不同阶段具有箭矢、奥术、火焰、闪电、冰霜减速、毒伤和暴击等效果。选中塔可以查看实际攻击、射程与攻击间隔。

部分等级可以安装攻击、治疗或真视附塔；当前每座主塔只保留一个附塔位。附塔的解锁前置、价格与效果可在面板查看。生死塔可在建筑目录中独立建造，占用一个塔基座，兼有攻击与治疗效果。

精灵魔法上限为 200，每游戏秒恢复 3。技能消耗与冷却：

| 技能 | 按键 | 魔法 | 冷却 | 效果 |
| --- | --- | ---: | ---: | --- |
| 闪烁 | Q | 0 | 19 秒 | 选择有效落点，最多位移 250，可越墙 |
| 缠绕 | E | 75 | 35 秒 | 控制巨魔 3 秒，阻止移动与攻击 |
| 神之护盾 | Z | 0 | 600 秒 | 主墙免伤 10 秒 |
| 沉默 | W | 75 | 60 秒 | 阻止巨魔主动技能 5 秒，普通攻击继续 |
| 侦察守卫 | V | 100 | 30 秒 | 揭示入口隐身巨魔，持续 200 秒 |
| 星辰之夜 | N | 100 | 60 秒 | 切换夜间光照 |

缠绕和沉默要求巨魔在范围内且已经被发现。标准局巨魔入场与补给后会使用隐身，侦察守卫或真视附塔可以揭示它。

巨魔有独立资源和最多 6 格装备背包。攻墙造成的实际伤害会转为金币，护盾免伤时不会获得这部分金币。标准局由巨魔回店后自动购买装备；玩家可以查看六个商店的库存与属性。练习场可以手动购买装备和触发巨魔技能。

## 6. 鼠标、触屏与快捷键

| 操作 | 方法 |
| --- | --- |
| 移动精灵 | 点空地 |
| 选择建筑或单位 | 点目标 |
| 移动视野 | 拖动地图，或点小地图 |
| 缩放视野 | 电脑鼠标滚轮 |
| 修墙或继续施工 | 选中建筑后使用对应命令；电脑也可右键建筑 |

倍速会同时加快资源生产、施工、战斗、强化和技能冷却。新手建议先使用 1 倍速。暂停时不接受升级、交易或施法操作。

| 按键 | 操作 |
| --- | --- |
| 1 / 2 / 3 / 4 | 建房 / 建墙 / 建塔 / 建远古之树 |
| U / R / S | 升级 / 修墙 / 停止 |
| Q / E / Z / W / V / N | 闪烁 / 缠绕 / 护盾 / 沉默 / 侦察守卫 / 夜间光照 |
| B | 建筑目录 |
| F1 / 空格 | 选择并定位精灵 / 定位精灵 |
| Esc | 取消放置 |

├── README.md                # 启动与玩法说明

## 8. 当前范围与常见问题

- **当前是单机原型**：一名玩家精灵，没有 AI 精灵队友、多人房间、账号或排行榜。
- **地图是一处固定窄口营地**：主墙、塔与经济建筑采用固定基座，巨魔的进攻和补给由简单规则驱动。
- **美术为二维素材**：角色主要使用四帧、左右朝向动画，当前没有三维骨骼或八方向动作。
- **经典机制经过网页适配**：施工速度、射程比例、附塔槽位、单机成长节奏以及单建筑采木升级采用本项目实现。

| 问题 | 排查方式 |
| --- | --- |
| 打不开页面 | 确认服务终端仍在运行、地址和端口正确 |
| 一直显示载入或资源失败 | 用 HTTP 地址打开，查看浏览器控制台；确认 `game/assets/` 文件完整 |
| 无法建造 | 点对应固定基座，确认资源、科技前置与建筑数量限制 |
| 无法升级 | 等待建造或当前升级完成，补齐所需科技与资源 |
| 木材不增加 | 先建大厅，再建成远古之树；升级该建筑提高产量 |
| 金币增长没有变快 | 查看经济面板的房屋和矿收入，升级产金建筑 |
| 塔不攻击巨魔 | 检查射程、建筑是否完工，以及巨魔是否隐身 |
| 代码更新后仍显示旧界面 | 刷新页面；刷新会重开本局 |
