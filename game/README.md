# 游戏目录说明

完整的下载、启动、操作、经济数值和常见问题见 [项目 README](../README.md)。本目录是可以通过静态 HTTP 服务运行的游戏页面。

## 模块职责

| 文件 | 职责 |
| --- | --- |
| `index.html` | 页面结构、战场、资源栏、命令和选择面板 |
| `style.css` | 界面视觉、桌面布局与手机横屏适配 |
| `game.mjs` | 输入与镜头、菜单、Canvas 绘制、动作和特效 |
| `simulation.mjs` | 寻路、碰撞、施工、经济、技能、装备、巨魔成长与胜负 |
| `classic-data.mjs` | 参考地图的单位等级、价格、前置、物品和商店数据 |
| `test.mjs` | 可用 Node.js 运行的规则与战局模拟检查 |
| `assets/` | 页面运行所需的本地素材 |

`game.mjs` 使用 `simulation.mjs` 的同一份状态进行显示；碰撞、升级扣款和资源增长在模拟模块中处理。主循环通过多个小步长推进高倍速对局。

## 当前的网页适配

- 固定建筑基座，主墙占据唯一窄口；每类经济建筑一座、防御塔最多三座。
- 远古之树加八档伐木场组成单建筑升级链，替代采木者招募与人口管理。
- 金矿由精灵直接施工，无需金矿建造者。
- 主塔只显示相邻升级，主塔和附塔只有一个可用选项时直接执行；每塔保留一个附塔位。
- 标准局巨魔自动入场、周期强化、回店补给换装；精灵或巨魔死亡即结束单机局。

参考数据与适配数据有所区分：`classic-data.mjs` 保存数值参考，`simulation.mjs` 构建采木建筑升级链并实现单机规则。调整玩法时应同时检查面板中的费用、前置、产量与实际效果。

素材来源、动作帧对齐和生成提示词见 [ART_NOTES.md](ART_NOTES.md)。
