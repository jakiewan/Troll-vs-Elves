# 雪林防线：单机守卫战

从工作区根目录启动：

```bash
python3 -m http.server 8765 --directory game --bind 127.0.0.1
```

在电脑浏览器打开 `http://127.0.0.1:8765/`；手机在同一局域网试玩时，用本机局域网 IP 启动服务并横屏打开。默认是标准局：一名玩家操控精灵，30 秒后巨魔自动入场，每 90 秒强化，受伤会回店补给再进攻。玩家精灵死亡判巨魔胜，巨魔死亡判精灵胜。练习局可免费逐阶建造和升级，用于查看塔型与测试技能。

操作：点地图移动，拖动地图平移，滚轮缩放；建筑只能放在标记的固定基座。底部命令选建房、主墙、塔，再点基座；人物会走近并施工。连续下达建造命令会排队，移动或按 `S` 会取消施工队列。点选主墙后按 `R` 让精灵免费持续修墙，移动或按 `S` 中断。点选建筑后打开“升级”：单一升级点一次即开始；主塔有分支时再选择，附塔页另列当前可建的辅助塔。远古之树有一个连续升级链来提高产木。`B` 建筑目录、`Q` 闪烁、`E` 缠绕、`Z` 护盾、`W` 沉默、`F1` 回精灵。右侧菜单包含金矿、木材升级、金木交易和巨魔的六处商店库存。

本地数据来自英文地图 *Troll vs. Elves v4.7 B5.5* 的单位、技能、物品与触发配置：10 档收入建筑、18 档主墙、13 档主塔、附塔、科技前置和商店物品均已导入 `classic-data.mjs`。网页地图为一处原创窄口，塔的有效伤害、射程显示比例、附塔固定槽、施工速度及巨魔自动成长属于单机适配参数。原地图文件不作为游戏素材发布；地图背景、角色图、图标都在 `game/assets/` 本地提供。

验证：`node game/test.mjs` 检查封墙碰撞、免费近身修理、逐阶升级、技能及装备效果，并用标准起始资源模拟胜负闭环。浏览器手动验收还应分别在电脑与手机横屏检查触控位置和文字大小。

本轮更新：施工命令排队、重复施工去重；紧急修墙会取消施工队列并立即执行，未完成建筑可点选后继续施工。暂停时禁止技能、升级、交易和试炼操作。每个固定塔位都已验证能覆盖墙外攻击点，射程圈与塔的实际射程一致。

画面：主墙按升级阶段切换石墙、加固墙、符文墙；精灵修墙与巨魔攻击使用独立动作图，按脚底锚点对齐。行走按实际距离播放，攻墙动作跟随真实攻击间隔。新增发射光、命中闪光、冲击波和施法光效。素材说明见 `ART_NOTES.md`。当前仍是四帧、左右朝向的二维动画，尚未实现八方向角色或三维骨骼动画。

金矿由精灵直接建造，不需雇佣建造者；标准局基础矿消耗 32 木、建成后产金 1/秒，下一阶旧金矿消耗 256 木、产金 8/秒。经济面板显示房屋与矿的收入组成，可直接进入金矿升级。
